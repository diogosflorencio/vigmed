## Sistema VigMed

Plataforma para gerenciamento de arquivos, usuários e diversas outras funcionalidades.

Stack usada:

`Front Next.js usando approutes, hospedagem Vercel para uso de variáveis de ambiente e CI facilitado com o github, Supabase com PostgreSQL, Auth (Google + e-mail/senha) e RLS, Cloudflare R2 para armazenamento de arquivos com URLs assinadas, Tailwind CSS para desing junto ao shadcn e Framer Motion para animações. Conforme for crescendo vou adicionando aqui o que mais está sendo usado e descrevendo melhor as funcionalidades.`
